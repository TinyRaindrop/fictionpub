## Можливості

* **Пакетна конвертація** — додавання окремих файлів, папок або їх комбінацій; обробка відбувається паралельно.
* **Точне відтворення** — структура, вміст і метадані FB2 зберігаються в EPUB.
* **Коректна розмітка** — валідний XHTML із семантичними тегами; без незрозумілих `<div class="123">`.
* **Зміст (TOC)** — налаштовувана глибина заголовків (h1–h6) для EPUB3 nav і EPUB2 NCX.
* **Семантика приміток** — розмітка EPUB3 `epub:type` дозволяє читачам відображати примітки внизу сторінки або у спливаючих вікнах.
* **Сумісність з EPUB2** — генеруються NCX та `<guide>` поряд із EPUB3 структурами.
* **Підтримка стилів** — вбудований CSS; можна використовувати власний `.css`.
* **Проходить epubcheck** — результат відповідає специфікації EPUB3.

**Інтерфейс користувача**

* Українська / Англійська мови.
* Світла / Темна тема.
* Перегляд / редагування CSS.
* Перегляд логів.

**Заплановано**

* Типографічна обробка (нерозривні пробіли, no-break span).
* Оптимізація зображень (зменшення розміру JPEG, pngquant для grayscale PNG).
* Розбиття великих XHTML-файлів на менші для швидшого рендерингу.
* Коректна обробка нестандартних структур FB2.
* Автооновлення програми.

## Використання

### GUI (основний спосіб)

Завантажте `fictionpub.exe` зі сторінки [Releases](https://github.com/TinyRaindrop/fictionpub/releases/latest). Програма портативна, встановлення не потрібне.

**Базовий процес:**

1. **Додати файли** — кнопки *Додати файл* / *Додати папку*, або просто перетягти файли у вікно. Підпапки скануються рекурсивно.
2. **Налаштування** — *⚙ Налаштування*: глибина змісту, рівень розбиття, папка виводу, CSS.
3. **Папка збереження** — *В тій самій папці* або власна папка (з можливістю збереження структури).
4. **Конвертація** — кнопка **Конвертувати**. Статуси (✓ / ⚠ / ✗) відображаються в реальному часі.
5. **Логи** — клік по статусу відкриває лог файлу. На нижній панелі є доступ до всіх логів.

Статус ⚠ Warning позначає успішну конвертацію, але в FB2 було виявлено незначні проблеми (відсутнє зображення, неправильне посилання чи примітка, тощо). Статус ✗ Failure – невдача, EPUB не створено.

Подвійний клік успішно конвертованого (✓/⚠) файлу відкриває EPUB.
Правий клік — контекстне меню.

### CLI

```
fictionpub_cli.exe <input> [options]
```

`<input>` — один або кілька `.fb2` / `.fb2.zip` файлів або папок, розділених пробілом.

| Опція | Типове значення | Опис |
|---|---|---|
| `-o, --output PATH` | поруч із джерелом | Папка виводу |
| `-t, --toc-depth N` | `4`  | Максимальний рівень заголовків у TOC (1–6) |
| `-s, --split-level N` | `2` | Рівень розбиття глав (1–6) |
| `-c, --css PATH` | вбудований | Шлях до CSS |
| `--threads N` | `0` | Кількість процесів (0 = авто) |

**Приклади:**

```bash
# Один файл, результат зберегти у тій же папці
fictionpub_cli.exe book.fb2

# Конвертувати всі в папці D:\books\, результати зберегти до E:\output\
fictionpub_cli.exe D:\books\ -o E:\output\

# Кілька папок, глибший зміст (6 рівнів), 4 паралельних потоки
fictionpub_cli.exe D:\books\ E:\docs\ -o E:\output\ -t 6 --threads 4
```

Запустіть `fictionpub_cli.exe --help` для відображення довідки.

## Встановлення

### Як Python package

Потрібен **Python 3.12+**.

```bash
pip install git+https://github.com/TinyRaindrop/fictionpub.git
```

Запуск GUI:

```bash
python -m fictionpub
```

Запуск CLI:

```bash
python -m fictionpub <input> [options]
```

Працює на Windows, macOS, Linux. GUI використовує Qt6/PySide6.

---

### Для розробки

```bash
git clone https://github.com/TinyRaindrop/fictionpub
cd fictionpub
pip install -e ".[dev]"
```

**Компіляція `.exe` за допомогою Nuitka**:

```bash
python build.py
```

Вимоги для збірки `.exe`:

* MSVC або MinGW-w64 (оберіть потрібний варіант в `build_exe.py`)
* `make` — опціонально для makefile скриптів (`make exe`) (встановлення: `winget install GnuWin32.Make`)
